# Add Structure Break Event

## Why

Market Structure already becomes undefined when price closes beyond the confirmed swing that sustains a directional trend. Observatory also needs to record that precise change as a dated Event without treating it as a prediction, recommendation, or automatic reversal.

## What Changes

Add pure, session-aligned detection of Structure Break Events to the existing technical-analysis module. A break uses the directional Structure and defining confirmed swing known on the previous completed session, occurs only on a strict completed close beyond that level, and is recorded once.

The Event carries structured Evidence about the prior Structure, break direction, defining confirmed swing, and closing price. ATR magnitude, penetration distance, Regime, Situations, Opportunities, Observations, notifications, persistence, wording, scores, generalized detector frameworks, and other Event types remain outside this capability.
